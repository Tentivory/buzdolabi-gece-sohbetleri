# 🌕 Buzdolabı Gece Sohbetleri

## Bilimsel Özet

Bu repository, insanlığın en büyük sırlarından birini çözmek üzere tasarlanmıştır: **Gece yarısı buzdolabı neden konuşur?**

Yıllarca göz ardı edilen bu fenomen, artık bilimsel olarak modellenmiştir. Kodumuz, buzdolabının içindeki gıda maddeleriyle yaptığı derin, varoluşsal ve tamamen absürt sohbetleri gerçek zamanlı olarak simüle eder.

> **Uyarı:** Bu kod sadece gece 03:00 - 04:00 arasında doğru sonuç verir. Diğer saatlerde çalıştırmak bilimsel etiğe aykırıdır.

## Özellikler

- Rastgele konu seçimi (süt krizi, yumurta ihaneti, peynir sanati vs.)
- Gerçekçi diyalog üretimi
- Bilimsel sonuç raporu
- Gece modu (görsel efektler terminalde)

## Kurulum ve Kullanım

```bash
python3 buzdolabi.py
```

Çıktı örneği:
```
🌙 Buzdolabı Gece Sohbeti Başlıyor... (03:14) 🌙

[Konu: Sütün son kullanma tarihi ile varoluşsal kriz]

Buzdolabı: Bugün de kimse beni açmadı. Acaba var mıyım?
Süt: Ben buradayım, sen de buradasın. Yeter.
```
